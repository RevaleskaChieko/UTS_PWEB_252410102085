Ini adalah website pengelolaan turnamen esports yang saya buat untuk tugas UTS Pemrograman Web. Di website ini admin bisa login, melihat dashboard, melihat profil, dan mengelola data tim serta jadwal pertandingan.

Website dibuat menggunakan Laravel dengan konsep MVC dan Blade. Tidak memakai database, jadi datanya berupa array yang dikirim dari controller ke view.
